# 智能网文小说创作工作台

> 面向「穿越题材 + 高阳毒士风格」长篇网文的一站式生产流水线：**规划 → 生产 → 质检 → 纪律**。
> 本仓库除流水线与脚本外，还包含一个可在浏览器直接阅读全文的 **Web 阅读器**，以及长篇正文的 **259 章样本源稿**。

**作者**：屋顶那只猫（[@tiger5325](https://github.com/tiger5325)）

## 🔗 在线预览

- **GitHub Pages 阅读器**：https://tiger5325.github.io/novel-workbench/
- Pages 版为**只读浏览**；在线编辑 / 保存（`/api/save`）依赖本地 Python 服务，见「快速开始」。

## 这是什么

把长篇网文的生产拆成可复用的流水线段，配套确定性机检（格式 / 字数 / 引号 / 违禁词 / 跨章重复）与八轴深度审校，解决「写作进度与审检进度不同步」的老问题。产物既有结构化的规划文档，也有可直接发布的 Web 阅读器数据。

## 样本正文（novel-source/）

仓库附《穿越之我是杨广》**259 章原始 markdown**作为样本参考，便于理解流水线产物格式与文风：

## 目录结构

```
.
├─ web/                 # Web 阅读器 + 构建
│  ├─ index.html        # 单页阅读器（总览 / 阅读 / 搜索 / 编辑）
│  ├─ data.js           # 由 build.py 打包的成品数据（含 259 章）
│  ├─ build.py          # 扫描正文 md → 生成 data.js
│  ├─ server.py         # 本地服务（支持在线写回 .md）
│  └─ serve_threaded.py
├─ novel-source/        # 259 章原始 markdown（样本）
│  ├─ 卷一_龙潜于渊/
│  ├─ 卷二_定鼎新朝/
│  └─ 卷三_宏图初展/
├─ projects/            # 规划层文档（总纲 / 人物库 / 时间线 / 逐章大纲 / 伏笔追踪 …）
├─ benchmark/           # 顶流基准包（文风向量、拆解实例）
├─ .eval/               # 评审证据与评分卡
├─ 00-06*.md            # 流水线各阶段说明（题材 / 人物卡 / 文风 / 伏笔 / 质检 / 对标）
└─ qc_audit.py          # 确定性质控机检脚本
```

## 快速开始

**仅浏览（零依赖）**：直接打开 `web/index.html`，或起本地静态服务——
```bash
python3 -m http.server 8000 --directory web
```

**重新构建 data.js**（扫描正文 md 打包）——
```bash
python3 web/build.py
```

**本地服务（支持在线编辑写回 .md）**——
```bash
python3 web/server.py    # 浏览器访问 http://127.0.0.1:8770
```

**确定性质控机检**——
```bash
python3 qc_audit.py
```
