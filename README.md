## Web 版（推荐入口）
本工作台已做成 Web 版，所有文档与**全部正文**可直接在网页上浏览、审阅、搜索、编辑：
- **线上站点（首选）**：浏览器打开 `https://novel-workbench-30059.app.workbuddy.host/?sharecode=BAA7NLNGYH`——自动加载最新 `data.js`，无需本地服务、无需登录，手机/电脑均可访问。
- **打开即用**：浏览器打开 `web/index.html`（自包含，文档与正文全部内嵌，双击即可）。
- **实时同步**：页面每 2.5 秒轮询 `data.js` 版本戳——改完稿跑一次 `web/build.py`，所有打开着的页面**自动换成新内容**，不用手动刷新。
- **改磁盘**：启动本地服务 `F:/F03_Deps_Hub/Python_Local/bin/python.exe web/server.py`，访问 `http://127.0.0.1:8770`，编辑保存会**直接写回 .md**（自动 `.bak` 备份 + 重建 data.js）。
- **功能**：总览看板 / **正文阅读器**（170 章，按卷分组、上下章翻页、局点与伏笔随文显示、字号调节）/ 章节进度板（001–170）/ 全文搜索（Ctrl/⌘+K）/ markdown 在线编辑（保存·导出）/ 深浅主题。

> **数据来源说明**：工作台 Web 版的正文与细纲由 `web/build.py` 从独立稿库 `F:/F05_Projects_Hub/穿越之我是杨广/`（正文_精修版 + `07_逐章大纲_*.md`）实时打包进 `web/data.js`；工作台 `projects/` 目录只放规划层文档，**正文稿不放在工作台目录内**——所以「工作台文件夹里看不到稿子」属正常架构，正文都在线上站点里。

## 怎么用（5 步上手）
1. 开 `01` 锁朝代（隋末/秦末二选一）+ 毒士定位 + 核心爽点
2. 开 `02` 建毒士主角人物卡（★语言/动机决定毒士味）
3. 开 `06` 顶流对标（选 1~3 部顶流 → 文风提炼 + 拆解模仿 → 基准包）→ 开 `03` 提炼毒士文风（贴范文 → 跑出文风向量 + 语言铁律）
4. 开 `04` 铺前 10 章大纲 + 伏笔矩阵（凡埋必收）
5. 写 → 过 `05` 质检 → 自进化控制台（novel-factory-console）闭环

> 完整路由与 Stage 0–6 七阶段闭环见 `00-流水线总览与路由.md`。
